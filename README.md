# Daily Islam

কুরআন, হাদিস, নামাজের সময়, কিবলা ও দৈনন্দিন দোয়া — একজন মুসলিমের প্রতিদিনের প্রয়োজনীয় সবকিছু এক অ্যাপে।

## অ্যাপে যা আছে

- সম্পূর্ণ কুরআন — আরবি পাঠ, বাংলা অনুবাদ ও তাফসির; তিলাওয়াতের অডিও অফলাইনেও শোনা যায়
- সহিহ বুখারি, মুসলিমসহ ছয়টি বড় হাদিসের কিতাব বাংলায়
- কওমি মাদরাসার প্রধান কিতাবসমূহ, পিডিএফসহ
- জেলা অনুযায়ী নামাজের সময়, আজান অ্যালার্ম ও হোম-স্ক্রিন উইজেট
- কিবলা কম্পাস, ডিজিটাল তাসবিহ, যাকাত ক্যালকুলেটর, হজ-ওমরা গাইড ও ইসলামিক কুইজ
