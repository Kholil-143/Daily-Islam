# Daily Islam

কুরআন, হাদিস, নামাজের সময়, কিবলা, তাসবিহ ও দৈনন্দিন দোয়া — একজন মুসলিমের
প্রতিদিনের প্রয়োজনীয় সবকিছু এক অ্যাপে।
এই রিপোজিটরিতে অ্যাপটির সম্পূর্ণ কোড আছে, আর GitHub থেকেই Android APK
বানিয়ে ফোনে ইনস্টল করা যায়।

## প্রথমবার শুধু একটিমাত্র হাতে করা ধাপ (workflow ফাইলটি বসানো)

GitHub-এর অনুমতির সীমাবদ্ধতার কারণে বিল্ডের workflow ফাইলটি সরাসরি `.github/workflows/` ফোল্ডারে
বসানো যায়নি। তাই প্রথমবার শুধু এই একটি ধাপ হাতে করতে হবে (Chrome ব্রাউজারে github.com খুলে করলে সহজ হবে):

1. এই রিপোজিটরিতে **WORKFLOW-build-apk.yml.txt** ফাইলটি খুলুন এবং ভেতরের লেখা সবটা কপি করুন।
2. রিপোজিটরির উপরে **Add file → Create new file** চাপুন।
3. ফাইলের নামের জায়গায় হুবহু লিখুন: `.github/workflows/build-apk.yml`
4. নিচের বড় বাক্সে কপি করা লেখা পেস্ট করুন।
5. সবুজ **Commit changes** বোতাম চাপুন।

ব্যস — workflow তৈরি হয়ে গেল। এরপর থেকে নিচের ধাপে APK বানানো যাবে।

## ফোনে ইনস্টল করার জন্য APK বানানো

1. GitHub অ্যাপে (বা github.com-এ) এই রিপোজিটরি **Daily-Islam** খুলুন।
2. উপরের **Actions** ট্যাবে যান।
3. বাম পাশের তালিকা থেকে **Build Android APK** বেছে নিন।
4. ডান পাশে **Run workflow** বোতামে চাপ দিন, তারপর সবুজ **Run workflow** বোতামটি আবার চাপুন।
5. বিল্ড শেষ হতে কয়েক মিনিট অপেক্ষা করুন। তালিকায় সবুজ টিক (✓) এলে বুঝবেন তৈরি হয়ে গেছে।
6. শেষ হওয়া বিল্ডটিতে ঢুকুন, নিচে **Artifacts** অংশে **Daily-Islam-APK** নামে একটি ফাইল পাবেন — সেটি ডাউনলোড করুন।
7. ডাউনলোড করা zip ফাইলটি খুললে ভেতরে **app-debug.apk** পাবেন। সেটিতে চাপ দিয়ে ইনস্টল করুন।
   ফোনে "অজানা অ্যাপ ইনস্টল" (Install unknown apps) অনুমতি চাইলে Allow দিন — এটি আপনার নিজের বানানো অ্যাপ।

বিল্ডের সময় workflow নিজে থেকেই `widget/` ফোল্ডারের হোম-স্ক্রিন উইজেটটি
Android প্রজেক্টে বসিয়ে দেয়, তাই APK-তে উইজেটটিও সাথে থাকে।

- কুরআন শিক্ষা (আরবি হরফ ও তাজউইদ), সুন্নাহ আমল, বুকমার্ক ও শেষ পড়া মনে রাখা
- লাইভ ঘড়ি (সেকেন্ডসহ), ইংরেজি-বাংলা-হিজরি তারিখ, ডার্ক/লাইট থিম, Google সাইন-ইন
- হোম স্ক্রিন উইজেট — নামাজের সময়, লাইভ ঘড়ি, তিন তারিখ, পরের ওয়াক্তের
  কাউন্টডাউন ও রিফ্রেশ বোতাম (`widget/` ফোল্ডারে এর কোড আছে)

## ফাইলের তালিকা

- `index.html.part-000`, `index.html.part-001`, … — অ্যাপের মূল ফাইল `index.html` অনেকগুলো
  ছোট ভাগে ভাগ করে রাখা (ফাইলটি বড় বলে, প্রায় ৬.৬ মেগাবাইট)। APK বানানোর সময় বিল্ড নিজেই
  সব ভাগ জোড়া দিয়ে আসল `index.html` বানিয়ে নেয়।
- `assets/` — আইকন, ম্যানিফেস্ট ও অফলাইন সার্ভিস ওয়ার্কার।
  বড় আইকনের ছবিগুলো `.png.b64` লেখা-আকারে কয়েক ভাগে (`.part-0`, `.part-1` …) রাখা আছে;
  বিল্ড নিজেই সেগুলো জোড়া দিয়ে আসল `.png` ছবিতে ফিরিয়ে নেয়।
- `capacitor.config.json`, `package.json` — ওয়েব অ্যাপ থেকে Android অ্যাপ বানানোর সেটিংস
- `widget/` — নেটিভ হোম-স্ক্রিন উইজেটের কোড ও বিল্ডে বসানোর স্ক্রিপ্ট
  (`widget/README.md`-তে বিস্তারিত আছে)
- `WORKFLOW-build-apk.yml.txt` — APK বানানোর workflow-এর লেখা (উপরের ধাপ দেখুন)
